Minimum pilot preparation. This workspace has been initialized for human review. Data download, data auditing, model training, and experiment execution are not currently authorized.

## Authoritative document reading order

1. `research/00_RESEARCH_CHARTER.md`
2. `research/01_DECISION_LOG.md`
3. The currently approved task in `research/tasks/`
4. Relevant configuration in `configs/`
5. Related reports and experiment registry entries

## Repository layout

- `research/`: charter, decisions, experiment registry, evidence mapping, review checklist, and approved tasks.
- `configs/`: versioned experiment configurations.
- `data/`: immutable raw data, versioned processed data, and split definitions.
- `src/`: data, feature, model, and evaluation code.
- `scripts/`, `tests/`: executable entry points and tests.
- `runs/`, `reports/`: immutable formal-run outputs and research reports.
